# 🔫 Mad Mullet Jack 모작 (DirectX 9)

> DirectX 9 기반의 1인칭 하이퍼 액션 슈터 게임을 모작한 팀 프로젝트입니다.  
> 상용 엔진의 구조를 차용하여 **엔진 프레임워크 전반의 뼈대와 컴포넌트 시스템, FPS 전투 및 UI 구조**를 직접 설계하는 데 집중했습니다.

## 🚀 주요 담당 구현 기능

### 1. 엔진 프레임워크 아키텍처 설계
* **계층 기반 업데이트 구조:** `Scene -> Layer -> GameObject -> Component`로 이어지는 체계적인 매 프레임 업데이트 실행 흐름 확립
* **Prototype-Clone 객체 생성 패턴:** 원본 객체를 미리 관리하고 복제(Clone)하는 방식을 도입하여 객체 생성 및 관리 효율성 극대화
* **컴포넌트 조합형 구조:** Transform, Renderer, Collider, Texture, VIBuffer 등 기능을 컴포넌트 단위로 분리하여 유연한 조립 가능하도록 설계

### 2. 충돌 및 피킹 시스템 구현
* 오브젝트 간 충돌 판정 및 마우스 피킹(Picking) 시스템을 구현하여 1인칭 시점에서의 상호작용 처리

### 3. UI 시스템 전체 구조 설계 및 연출
* 처치 UI, 콤보 UI, 클리어 게임 시작 UI 등 하이퍼 액션 장르에 맞는 동적인 전투 연출 UI 구현
* 몬스터 부위 판정(Head / Body) 시스템과 연동되는 피격 및 상태 표시 UI 구조 설계

## 💡 트러블 슈팅 및 배운 점
* **객체 간 결합도 낮추기:** 초기 설계 시 매니저 객체들과 컴포넌트 간의 참조가 엉키던 문제를 프로토타입 패턴과 컴포넌트 분리 구조를 적용해 리팩토링함으로써 확장성 개선
* **FPS 전투 피드백 강화:** 1인칭 슈터 특유의 빠른 템포를 살리기 위해 피격 판정과 UI 연출 간의 타이밍 동기화 최적화 진행
